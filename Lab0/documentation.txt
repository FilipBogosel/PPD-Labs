Lab 0 - PPD - Vector Addition

1. Requirements Analysis
- Write a program that adds two vectors in C++ and Java.
- Measure the execution time of the addition (ignoring file reading/writing).
- Run it at least 10 times and calculate the average time.
- Verify that the outputs match the expected results.

2. Design
- Data Structures: I used std::vector<double> in C++ and double[] in Java.
- Thread Partitioning: This is a sequential version, so everything runs on the main thread (the thread argument is ignored).
- Functions used:
  - readInput: Reads the size and the vectors from the file.
  - addVectors: Does the actual math (C[i] = A[i] + B[i]).
  - writeOutput: Saves the result to a file.
  - main: Handles the arguments, timing, and calling the other functions.

3. Implementation Details
- C++ uses std::chrono for timing and is compiled with g++ -O3.
- Java uses System.nanoTime() for timing.
- I wrote some simple bash scripts (run_cpp, run_java, repeat) to automate running the programs 10 times and saving the times to a csv file.

4. Test Cases
- I tested with input sizes of 1,000, 10,000, and 100,000 elements.
- Each test was run 10 times to get a stable average.

5. Results Analysis
- Average times for C++:
- 1,000 elements: ~0.0004 ms
- 10,000 elements: ~0.0067 ms
- 100,000 elements: ~0.0596 ms

- Average times for Java:
- 1,000 elements: ~0.0088 ms
- 10,000 elements: ~0.0697 ms
- 100,000 elements: ~0.5911 ms
